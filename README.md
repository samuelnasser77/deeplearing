# Handwritten Digit Recognition using CNN

## Project Description
This project implements a Convolutional Neural Network (CNN) to recognize handwritten digits using the MNIST dataset.

## Dataset
MNIST Handwritten Digits Dataset

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Experiments
Two experiments were performed using:
- Adam Optimizer
- SGD Optimizer

## Results
The CNN model achieved high accuracy in digit classification, with Adam optimizer providing better performance than SGD.
